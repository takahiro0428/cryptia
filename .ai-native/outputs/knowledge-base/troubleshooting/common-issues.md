# トラブルシューティング

## 価格が「参考データ（モック）」と表示される

- 原因: CoinGecko API に接続できない（オフライン・レートリミット・障害）
- 対処: ネットワーク接続を確認。15 秒ごとに自動で再接続を試みます。復旧すると警告は自動で消えます
- 直接接続できない環境（企業ネットワーク・広告ブロッカー）ではサーバープロキシへ自動フォールバックします

## 「DexScreener に接続できない」と表示される / 損益が動かない

- 原因: ブラウザから api.dexscreener.com へ到達できない（企業ネットワーク・広告ブロッカー・障害）
- 対処: 自動でサーバープロキシ経由に切り替わります。それでも表示される場合は警告バナーの「再試行」を押してください
- モック表示中は価格・損益が更新されません（バナーに明示されます）。復旧すると損益はリアルタイム更新（実行中 30 秒 / 一時停止中も約 10 秒間隔）に戻ります

## AI 分析が「テクニカル分析（AI未接続）」と表示される

- 原因: Vertex AI が未設定、または呼び出しに失敗（CRYPTIA-E201/E202）
- 対処: これは正常なフォールバック動作です。Gemini 分析を有効にするには運用者が
  `NUXT_GCP_PROJECT_ID` を設定し、Cloud Functions の SA に `roles/aiplatform.user` を付与してください

## デモトレードが注文をまったく出さない

- AI/ロジックは「明確なシグナルなし」では様子見（hold）します。相場が横ばいの間は正常です
- 注文履歴の代わりにコンソールに CRYPTIA-E401（資金不足）が出ている場合は現金が枯渇しています。セッションを終了し、新しいセッションを開始してください

## ウォレットが検出されない

- 対応ウォレット: Phantom / Bitget Wallet / Solflare / その他 Phantom 互換ウォレット
- PC: 各ウォレットのブラウザ拡張をインストール後、ページを再読み込み（検出は 2 秒ごとに自動再試行されます）
- スマホ: 通常ブラウザでは拡張が動きません。**各ウォレットアプリ内の DApp ブラウザ**でアプリ URL を開いてください

## 残高が「取得中…」のまま / 「残高を取得できませんでした（CRYPTIA-E505）」

- 原因: 公開 Solana RPC がブラウザからのリクエストを遮断・レートリミットしている
- 対処: 自動でサーバープロキシ経由に切り替わります。失敗が表示された場合は更新ボタン（🔄）で再試行してください
- 残高表示が取れなくても資産には影響しません（取引時にはウォレット側で残高が再検証されます）

## スワップが「見積り取得失敗（CRYPTIA-E504）」になる

- 流動性が薄いトークンでは金額を小さくすると通ることがあります
- Jupiter 側の一時障害の場合は時間を置いて再試行してください

## データが別端末に同期されない

- Firebase 未設定のデプロイではデータは端末ローカルにのみ保存されます（仕様）
- 設定済みでも同期は匿名認証の uid 単位です。ブラウザのサイトデータを消すと uid が変わり、過去データに紐づかなくなります

## PWA が更新されない

- 新バージョンは自動更新されますが、反映されない場合はアプリを完全終了して再起動、
  それでも直らなければブラウザのキャッシュから当サイトのデータを削除して再アクセスしてください
