# Solana 魔界トレード・実トレードの使い方

## 🌊 Solana 魔界トレード（デモ資金）

Solana チェーンの新興トークン（草コイン・魔界トークン）を対象にした自動取引です。
**取引はデモ資金で行われます。**
**セッションは複数同時に実行できます**（最大 3 件。例: ラダー枠と自動スナイプ枠の並走）。
各セッションは独立した資金・手法を持ち、個別に一時停止・再開・終了できます。市場データ（スクリーニング・監視プール・価格）の取得は全セッションで共有されるため、セッションを増やしても**市場データ取得**の負荷は増えません。対象トークンは**全手法とも 1 セッション 10 ペアまで**です（保有中の価格取得枠の都合）。一方 **AI 判断 API の呼び出しはセッション数 × 対象トークン数に比例**するため、AI 取引はさらに**全セッション合計 6 ペアまで**に制限しています（AI 判断 API のレート上限をデモトレードの AI エンジン・市場インサイト・実トレードの手動 AI 判断と分け合うための上限です。超過時は開始時に案内が表示されます）。AI 判断 API が混雑した場合はセッションカードに「AI混雑: ロジックで継続中」バッジが表示され、ロジックエンジンで取引を継続します。

### トークン選定

スクリーニングリストに DexScreener 由来のトークンが**スコア（0-100）**付きで表示されます。

- スコア内訳: 流動性 35% / 出来高 25% / モメンタム 20% / 成熟度 20%
- **取引適格** = 流動性 $50k 以上・ペア年齢 24h 以上・スコア 40 以上
- ⚠ 警告バッジ（流動性不足・超新規・垂直上昇・薄い板）は必ず確認してください
- **CA（コントラクトアドレス）の確認・コピー:** 各トークンカード下部の「CA: xxxx…xxxx」をタップすると
  その場で全文が展開されます（ページ遷移なし）。「コピー」ボタンでクリップボードへコピーでき、
  外部ツール（Solscan・DexScreener 等）での照合や実トレードでの指定に使えます。
  新規上場ハンターのカードにも同じ CA 行があります

### 取引手法

| 手法 | 動作 |
|------|------|
| **ラダーロジック** | 開始時に選択トークンへ等分エントリー。以後は「+100% で 50% 利確 → +300% でさらに 50% 利確 → -30% で全損切り」を機械的に実行 |
| **新規上場ハンター（スナイプ）** | 発行 48 時間以内の新規上場トークンを対象に、利益確保型ラダー「+50% で 30% 利確（早期の元本回収）→ +100% で 30% → +300% で 20% → 残り 20% は伸ばす / -40% で全損切り」を実行 |
| **自動スナイプ（常時監視）** | **トークンの選択は不要。**新規発行トークンを約 30 秒ごとの監視で**随時プールへ追加**し（固定リストではなくローリング監視: 48 時間で自動失効・最大 50 件保持・画面はおすすめ上位 10 件を表示）、最低限の監査を通過したトークンへ随時、等分予算（割当資金 ÷ 最大同時数）で自動エントリー。出口は新規上場ハンターと同じ利益確保型ラダー。一度エントリーしたトークンには再エントリーしない |
| **AI 取引** | 30 秒ごとに AI（Vertex AI / 未接続時はロジック）がスコア・戦略・含み損益から売買を判断 |

### 新規上場ハンターのトークン選定シグナル

新規上場リストの各トークンは、取得できる公開情報から**候補 / 要注意 / 回避**を判定します。

- **SNS の有無:** 公式サイト / X (Twitter) / Telegram（DexScreener token-profiles + ペア情報）
- **dev 情報:** mint 権限の放棄（増発不可）・freeze 権限の不在（凍結リスクなし）を Solana RPC で確認
- **初期流動性:** $5k〜$150k をスイートスポットとして評価（$2k 未満はラグプル警告で回避判定）
- **再発行チェック:** 同一シンボル / 同名の古いトークンが既に存在しないか照合（同一 dev のラグ後再発行の疑い。2 件以上で回避判定）
- **初動需給:** 24h の買い / 売り比率

シグナルは選定支援であり、安全性・利益を保証しません。取得できなかったシグナルは「不明 / 未照合」と表示され、判定に影響しません。

### 自動スナイプの「最低限の監査」（エントリーゲート）

自動スナイプは以下を**すべて**満たすトークンにのみエントリーします。

1. 総合判定が「候補」（設定で「要注意」まで許容可能）
2. 初期流動性 $5k 以上
3. mint 権限の残存が**判明していない**（増発可能と分かっているものは拒否。未取得=null は拒否しない）
4. freeze 権限の残存が**判明していない**（凍結可能と分かっているものは拒否）
5. 同名・同シンボルの再発行が 2 件未満

安全設計: 参考データ（モック）表示中や監視データが 5 分以上古い場合は新規エントリーを見送ります。
エントリーは**執行直前に最新価格を個別再取得**したうえで行います（取得できない場合は監視価格で継続）。
設定の「最大同時ポジション数」が資金の分散度を決めます（1 枠 = 割当資金 ÷ 本数）。
監視状況（監査通過数・累計エントリー数）はダッシュボードに常時表示され、
全量決済したトークンは監視対象から自動で外れます（再エントリーはしません）。

### 損益のリアルタイム表示と接続障害時の動作

- 保有ポジションの価格は実行中 30 秒ごと、**一時停止中も約 10 秒ごと**に更新され、損益はリアルタイムに反映されます（ダッシュボードに「価格更新: n 秒前」を表示）
- ブラウザから DexScreener に直接接続できない環境では、自動でサーバープロキシ経由に切り替わります
- それでも接続できない場合は参考データ（モック）表示となり、価格・損益は更新されません。警告バナーの「再試行」で再接続できます

### 保有ポジションのその場詳細

実行中ダッシュボードの保有ポジション行をタップすると、そのトークンの詳細が**その場に展開**されます
（ページ遷移なし・見たいときだけ表示・再タップで閉じる）。

- 現在価格 / エントリー価格 / 損益（USD・%）/ 数量・評価額
- 市場情報: 24h 騰落・流動性・出来高・発行からの経過・取引数
- **ラダーの残りライン**: 未発動の利確・損切りラインを目標価格つきで表示
  （例: 「+100% ($0.002) 残数量の43%を決済」。決済率は**その時点の残数量に対する比率**で表示されます。
  スナイプ系の残数量比 30% → 43% → 50% は初期数量比の 30/30/20 に対応します）
- 監査判定（新規上場リストに載っている場合）と **CA の確認・コピー**（トークンカードと同じ操作）

### 過去セッションの振り返り

セッション終了時に結果と約定履歴が「過去セッション」に保存されます。
行をタップすると、そのセッションの約定明細（判断理由つき）を閲覧できます
（容量保護のため、明細は直近 10 セッション・各 100 件まで保持されます）。

## ⚡ 実トレード（実資金・上級者向け)

ウォレットを接続し、Jupiter アグリゲーター経由で実際のスワップを実行します。
対応ウォレット: **Phantom / Bitget Wallet / Solflare / その他 Phantom 互換ウォレット**（検出されたウォレットがボタンで表示されます）。

### 事前準備（必須）

1. **ウォレット接続:** ブラウザ拡張（PC）または各ウォレットアプリ内の DApp ブラウザ（スマホ）で接続。
   残高が取得できない場合（CRYPTIA-E505）は RPC 混雑の可能性があるため、更新ボタンで再試行してください（サーバープロキシへ自動フォールバックします。取引時には残高が再検証されるため資産への影響はありません）
2. **リスク同意:** 取引ガードのチェックボックスで同意
3. **取引上限設定:** 1回あたり / 1日あたりの上限（USD）を設定

3 つが揃うまで注文はブロックされます（エラーコード CRYPTIA-E501）。

### 注文の流れ

1. 銘柄を選ぶ（🤖 AI おすすめ = スクリーニング適格上位 / 主要トークン）
2. 支払い SOL 数量を入力 → **見積りを取得**
3. 確認画面で受取数量・**価格影響**・スリッページを確認
4. **署名して実行** → 接続中ウォレットの署名画面で最終確認
5. 取引履歴の Solscan リンクでオンチェーン記録を確認

「🤖 AI に判断させる」を押すと、AI が推奨トークンを分析し、買い判断なら見積りまで自動で進みます（署名は必ず手動）。

### 売却（トークン → SOL）

注文パネルの「売る」タブに切り替えると、ウォレット内の保有トークンが残高付きで表示されます。
売却するトークンと数量（「全量」ボタンあり）を指定して見積りを取得し、内容確認 → 署名で実行します。
受取見込みの SOL と概算 USD は確認画面に表示され、取引ガードの上限判定にも同じ金額が使われます。

### 安全設計

- 秘密鍵がアプリに渡ることはありません（署名はウォレット内で完結）
- 上限超過の注文は自動拒否（CRYPTIA-E502）
- 実勢価格を取得できない間（価格 API 障害時）は見積り・発注・AI 判断が自動で一時停止します（架空価格での取引を防ぐ保護）

### 履歴のバックアップとアカウント連携

- 履歴セクションの「保存」で JSON をエクスポートし、「復元」で取り込めます（txid で重複排除）
- **Google アカウント連携**（実トレード画面・戦略画面のアカウントカード）を行うと、
  匿名 ID のままデータが引き継がれ、端末変更・データ消去後も同じデータへアクセスできます
- オンチェーンの原本はいつでも Solscan で確認できます
