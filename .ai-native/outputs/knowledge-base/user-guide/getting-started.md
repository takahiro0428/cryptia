# Cryptia はじめてガイド

Cryptia は仮想通貨・株式トークン・ゴールドトークンのトレードを AI が支援するアプリです。

## インストール（PWA）

1. ブラウザでアプリ URL を開く
2. **スマホ:** ブラウザメニューから「ホーム画面に追加」を選ぶとアプリとして起動できます
3. **PC:** アドレスバー右のインストールアイコンからインストールできます

## 画面構成

| 画面 | できること |
|------|-----------|
| 📊 マーケット | 主要 18 銘柄（仮想通貨・株式トークン・ゴールド）のリアルタイム価格を 15 秒間隔で自動更新。銘柄タップで詳細チャートと統計 |
| 🫧 フロー | 銘柄間の推定資金フローを空間バブルマップで表示。バブルの大きさ=時価総額、矢印の太さ=フロー量。バブルタップで流入・流出の内訳 |
| 🤖 AI分析 | 銘柄ごとに短期（〜1週間）・中期（〜1ヶ月）・長期（〜1年）の AI トレードアドバイス。ロング/ショート別のおすすめエントリーレンジ・根拠・リスク・参照ソース付き |
| 💹 トレード | デモトレード / Solana 魔界 / 実トレードへの入口 |
| 📚 戦略 | AI の売買判断をカスタマイズする戦略ドキュメントの管理 |

## 最初の 5 分でやること

1. **マーケット画面**で相場をひと通り確認する
2. **AI分析**で気になる銘柄の短期・中期・長期スタンスを見る
3. **戦略画面**でプリセット（順張りモメンタム / 逆張りリバーサル / DCA 積立 / ブレイクアウト追撃 / 魔界ラダー利確）から自分に合うものを選ぶ
4. **デモトレード**で初期資金（例: $10,000）を設定し、AI の自動売買を観察する
5. 注文履歴の「判断理由」を読み、AI がなぜ売買したかを理解する

## 重要な注意事項

- Cryptia は**投資助言を行いません**。すべての表示は情報提供・シミュレーションです
- 資金フローや AI 分析は推定・参考値であり、正確性・収益性を保証しません
- 実トレードは自己責任です。必ずデモトレードで検証してから利用してください
