# Phase 2: ユースケース一覧

「〇〇さんが△△の画面で□□を入力すると、××が表示される」レベルの具体シナリオ。

## UC-1: 市況の一目把握（毎朝・移動中）

トレーダーの山田さんがスマホで Cryptia を開くと、ホーム（マーケット）画面に BTC/ETH/SOL など主要銘柄のリアルタイム価格・24h 変動率・スパークラインがカード形式で表示される。銘柄をタップすると詳細チャートと AI インサイト要約が表示される。

- 入力: アプリを開く（操作なし）
- 処理: 価格 API から最新ティッカーを取得し 15 秒間隔で自動更新
- 出力: 価格カード一覧・変動率の色分け・スパークライン

## UC-2: 資金フローの空間把握（デイトレ前の状況確認）

山田さんがバブルマップ画面を開くと、主要銘柄が時価総額に応じた大きさのバブルとして空間に散らばり、銘柄間の推定資金フローが矢印（太さ＝フロー量）で描画される。バブルをタップすると当該銘柄の流入・流出の内訳が表示される。

- 入力: 表示期間（1h / 24h / 7d）の切替、バブルのタップ
- 処理: ティッカーの出来高・変動率から銘柄間フローを推定し、力学シミュレーションで空間配置
- 出力: バブルマップ＋フロー矢印＋銘柄別フロー内訳パネル

## UC-3: AI インサイトの閲覧（銘柄検討時）

山田さんがインサイト画面で銘柄（例: SOL）を選ぶと、短期（〜1週間）・中期（〜1ヶ月）・長期（〜1年）のタブごとに、AI の売買スタンス（強気/中立/弱気）・根拠（テクニカル指標・ニュース・資金フロー）・注意点が表示される。

- 入力: 銘柄選択、時間軸タブ切替
- 処理: サーバー API が市場データ＋ニュースを収集し Vertex AI (Gemini) で分析。AI 未設定時はテクニカル指標ベースのフォールバック分析
- 出力: 時間軸別インサイトカード（スタンス・根拠・リスク・生成時刻・分析ソース）

## UC-4: AI デモトレードの実行と振り返り

山田さんがデモトレード画面で初期資金（例: 100万円 or 10,000 USDT）と対象銘柄（AI おすすめから選択 or 手動選択）と戦略プリセットを設定し「開始」を押すと、AI が自動でデモ売買を行う。注文一覧には各注文の銘柄・売買・数量・価格・損益・AI の判断理由が時系列で並び、サマリーには総資産推移・勝率・最大ドローダウンが表示される。

- 入力: 初期資金、銘柄選択（AI推奨/手動）、戦略プリセット、開始/停止
- 処理: ティックごとに戦略＋AI 判断で注文を生成し、仮想ポートフォリオに約定させる
- 出力: 注文履歴（判断理由付き）、資産推移チャート、サマリー統計

## UC-5: Solana 草コインのスクリーニングと自動取引（デモ）

山田さんが Solana 画面を開くと、DEX の新興トークンが安全性スコア（流動性・年齢・出来高・価格変動の異常検知）付きでリストされる。トークンを選び、取引手法として「AI 取引」または「ロジック取引（+100% で 50% 利確、-30% で損切り等）」を選んで開始すると、デモ資金で自動取引が実行される。

- 入力: トークン選定（AI スコア順 / 手動）、取引手法選択、ラダー利確ルール設定
- 処理: DexScreener API からペア情報取得 → スコアリング → 選択手法で自動売買（デモ）
- 出力: トークンリスト（スコア内訳）、ポジション・約定履歴・利確/損切りイベントログ

## UC-6: ウォレット接続による実トレード

山田さんが実トレード画面で Phantom ウォレットを接続すると、ウォレット内の SOL/トークン残高が表示される。銘柄（AI おすすめ or 手動）と金額を指定すると Jupiter アグリゲーター経由のスワップ見積りが表示され、確認ダイアログで内容（レート・スリッページ・手数料）を確認して署名すると取引が実行される。AI 自動実トレードは明示的なリスク同意と取引上限設定の後にのみ有効化できる。

- 入力: ウォレット接続、銘柄・金額、リスク同意、取引上限
- 処理: Jupiter Quote API で見積り → スワップ Tx 生成 → ウォレット署名 → 送信・確認
- 出力: 残高、見積り（レート・スリッページ）、取引結果（Tx ハッシュ・エクスプローラリンク）

## UC-7: RAG 戦略設定

山田さんが戦略設定画面でデフォルト戦術プリセット（例: 順張りモメンタム / 逆張りリバーサル / DCA 積立 / ブレイクアウト / 防御的ヘッジ）から1つを選ぶ、またはカスタム戦略ドキュメント（自然言語のルール記述）を追加すると、以後の AI インサイト・デモ/実トレードの判断プロンプトに戦略コンテキストとして注入され、AI の挙動が変わる。

- 入力: プリセット選択、カスタム戦略テキスト、リスク許容度・最大ポジション比率
- 処理: 戦略ドキュメントを保存し、AI 呼び出し時に関連戦略を検索して文脈注入（RAG）
- 出力: 有効な戦略の表示、AI 判断理由への戦略引用

## システム化の仕分け

| 課題 | 仕分け |
|------|--------|
| 市況・フロー・ニュースの統合把握 | システム化（UC-1〜3） |
| 戦略の検証・ノウハウ蓄積 | システム化（UC-4, 7） |
| 新興トークンの選定 | システム化（UC-5）※最終投資判断はユーザー |
| 取引執行 | システム化（UC-6）※署名・リスク同意は必ずユーザー |
| 投資方針・リスク許容度の決定 | システム外（ユーザーの責務。アプリは投資助言ではない旨を明示） |
| 税務・法令対応 | システム外（スコープ外と明示） |
